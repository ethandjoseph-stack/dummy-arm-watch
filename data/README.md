# הנתונים

שישה קבצים. שני הראשונים באותו פורמט (LeRobotDataset v3, ‏30 שורות בשנייה). בכל שורה שלהם: לאן כל אחד מ-6 המפרקים של הזרוע **התבקש** ללכת (`action`), ואיפה הוא **באמת** (`observation.state`), במעלות. קבצים 3–6 הם מהזרוע האמיתית של Dummy, ב-9.11 וב-10–11.11, והפורמט שלהם מתואר בסעיף של כל אחד. *(עודכן: ב-9.11 נוספו קבצים 3–4, והמשפט עדיין אמר "שני קבצים". ב-11.11 נוסף קובץ 5, ובצהריים של אותו יום קובץ 6.)*
המפרקים, באותו סדר בשתי העמודות: `shoulder_pan`, `shoulder_lift`, `elbow_flex`, `wrist_flex`, `wrist_roll`, `gripper`.
